# Basic Playback

1. Add an `Animator` and `MontagePlayer` to a character.
2. Create a montage with **Assets > Create > Montage > Montage Asset**.
3. Add one `FullBody` slot track and an animation segment.
4. Add `BasicMontagePlayback` to a GameObject and assign the player and asset.
5. Call `Play`, `Stop`, or `JumpToSection` from gameplay code or a UI Button.
